# ThesisFlow — вариант C / Concept C UI

Принятый вариант оформления: горизонтальная навигация, компактные таблицы,
единые доступные светлая и тёмная палитры, Go html/template, без React и npm.

## Реализация / Implementation

- CSS-токены расположены в internal/web/static/theme.css и покрывают
  фон всего viewport, карточки, ссылки, кнопки, таблицы и формы.
- Активная кнопка меню имеет белый текст на синем фоне.
- В тёмной теме фон распространяется на html и body, чтобы
  узкая центральная колонка не оставляла светлых полос.
- Предпросмотр Excel получает класс tf-preview и семантические thead/th
  вместо первого tr/td; значения XLSX экранируются html/template.
- На страницах групп и шаблонов доступны общие пункты навигации.

## Ручная проверка / Manual QA

1. В светлой теме проверьте контраст активной кнопки.
2. В тёмной теме прокрутите страницу вверх и вниз — светлых полос быть не должно.
3. Откройте группу, шаблоны и предпросмотр настоящей книги XLSX.
4. Проверьте длинные ФИО, переносы заголовков, горизонтальную прокрутку
   таблицы и клавиатурную навигацию при масштабе 100–200%.
5. Повторите в Chromium и Firefox, на Windows и macOS.
6. Запустите go test ./..., go vet ./..., gofmt -l .

## Ограничения / Limitations

CSS-тесты не заменяют реальную проверку в браузере.
Визуальные макеты варианта C демонстрируют вымышленные колонки
«Направление», «Курс» и «Статус группы». Эти данные не добавляются
в SQLite и не отображаются без отдельного решения.

EN: The design system uses first-party local CSS and server HTML templates.
Buttons, dark surfaces, and the Excel preview follow the same tokens.
No third-party frontend dependency is introduced.
